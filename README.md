# 별똥별 피하기

화면을 좌우로 끌어 떨어지는 운석을 피하는 모바일 미니게임입니다. `index.html` 파일 하나로 동작하고, 빌드 과정은 없습니다.

- 조작: 화면 아무 곳이나 손가락으로 좌우로 끌기 (PC에서는 ← → 키)
- 점수: 버틴 시간 1초마다 10점, 별 하나당 50점
- 15초마다 레벨이 오르고, 운석이 점점 빨라지고 많아집니다.
- 운석 종류: 보통(빨강·주황·분홍), 작고 빠른 운석(하늘색, 8초~), 크고 느린 운석(보라, 15초~), 좌우로 흔들리는 지그재그 운석(초록, 30초~). 45초부터는 비스듬히 떨어지는 운석도 나옵니다.
- 5레벨마다 **운석 폭풍**: 경보 후 한 줄로 쏟아지는 운석 사이의 빈틈으로 빠져나가야 합니다. 통과하면 +200점, 별 3개.
- 오른쪽 위 ❚❚ 버튼(또는 P 키)으로 일시정지. 앱을 전환하면 자동으로 멈추고, 다시 시작할 때 3초 카운트다운이 있습니다.
- 모은 별(★)로 상점에서 캐릭터 색깔·모자·표정·꼬리 효과·배경을 사고 장착할 수 있습니다.
- 업적 14개: 달성하면 별 보상을 받고, 칭호를 달 수 있습니다.
- 효과음과 배경음은 Web Audio로 직접 합성합니다(소리 파일 없음). 시작 화면과 일시정지 화면에서 켜고 끌 수 있습니다.
- 최고 기록, 보유한 별, 산 아이템, 업적, 설정은 브라우저(localStorage)에 저장됩니다.

## 랭킹

Supabase에 점수를 모읍니다. 게임이 보내는 점수는 믿지 않고, **서버가 그 판을 다시 돌려서** 점수를 직접 계산합니다.

1. 판을 시작하면 서버가 운석 배치용 시드를 정해 줍니다(`start_run`).
2. 게임은 1/60초마다 캐릭터의 좌우 위치만 기록하고, 5초마다·일시정지·재개·종료 때 서버에 신호를 보냅니다(`heartbeat`).
3. 판이 끝나면 위치 기록을 Edge Function `verify-run`에 보냅니다. 서버는 같은 시뮬레이션 코드(`src/sim.js`)로 그 판을 재생해 점수·시간·별·폭풍 횟수를 계산하고, 신호 기록으로 슬로모션이나 일시정지 중 진행이 없었는지 확인한 뒤 기록합니다.

설치: `supabase/schema.sql`을 SQL Editor에서 실행하고, `supabase/functions/verify-run/index.ts`를 Edge Function `verify-run`으로 배포합니다(JWT 검증 끔).
관리: 이상한 기록은 Table Editor → `scores`에서 `hidden`을 체크하면 랭킹에서 빠집니다.
Claude 링크(artifact)에서는 외부 서버 연결이 막혀 랭킹이 동작하지 않습니다.

## 홈 화면과 앱 설치

- 홈 화면: 내 정보(닉네임·칭호·별·최고 점수·순위), 오늘의 도전, 게임 시작, 상점·업적·랭킹·설정·게임 방법
- 처음 온 사람에게는 환영 화면(닉네임, 조작법), 하루 한 번 출석 보상(7일 주기, 7일째 ★10)
- 앱 설치(PWA): `manifest.webmanifest`, `sw.js`, `icon-*.png`. 아이콘은 `python3 tools/make_icons.py`로 다시 만들 수 있습니다.

## 작업 방식과 점검 모드

- 수정은 `dev` 브랜치에서 하고, 확인이 끝나면 `main`에 합칩니다.
- GitHub Actions(`.github/workflows/pages.yml`)가 `main`을 사이트 루트에, `dev`를 `/dev/`에 배포합니다.
  `/dev/`는 관리자 키가 있는 기기에서만 열리고, 다른 사람에게는 "관리자 전용 미리보기" 화면만 보입니다.
- 관리자 기기의 홈 화면 아래에 "관리자 메뉴"가 생깁니다: 버전 전환, 통계(오늘·7일·전체: 판 수, 사람 수, 버틴 시간, 점수, 폭풍 통과율, 일별·레벨별·시간대별 그래프), 보상·화면 테스트, 테스트 판(무적·시작 레벨·속도, 랭킹 제외), 점검 모드 스위치, 랭킹 관리.
- 점검 모드: SQL Editor에서 `update public.app_config set maintenance = true where id = 1;` (끄기는 `false`).
  점검 중에는 관리자 키가 있는 기기만 게임을 시작할 수 있습니다. 관리자 키는 `owner_key`에 저장하고,
  휴대폰에서 `https://yookong.github.io/test-minigame/#owner-<키>`로 한 번 접속하면 기억됩니다.

## 개발

`index.html`과 `supabase/functions/verify-run/index.ts`는 생성 파일입니다. `src/`를 고친 뒤 빌드하세요.

```bash
python3 tools/build.py
```
